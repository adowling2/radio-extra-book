# References

This directory holds the source material the book is checked against. **Most of it is
gitignored**; two PDFs and their derived markdown are not.

## What is tracked, and why

| File | Tracked | Why |
|---|---|---|
| `HamExam.org Extra Question Pool.pdf` | ✅ | The NCVEC question pools are published for free reproduction — that is why every study site reprints them. Tracking them is what makes a pool citation checkable on a fresh clone. |
| `HamExam.org General Question Pool.pdf` | ✅ | Same. |
| `extra-pool-circuits.md` | ✅ | Derived. Generated by `../scripts/build_pool_md.sh`. |
| `general-pool-circuits.md` | ✅ | Derived. Same. |
| `ARRL_Extra_Class_Lcense_Manual_*.pdf` | ❌ | Commercial, copyrighted. |
| `Ham_Extra_Circuits_Study_Guide_First_Draft.docx` | ❌ | Alex's own draft; not needed to build. |
| Other study guides (KB6NU, etc.) | ❌ | Terminology cross-checks only. |

The manuals were used for topic-coverage and terminology checks only. No prose,
question, answer choice, or figure from them was copied into the book.

## The markdown files

Two greppable extracts of the circuits and calculation questions — 420 of 599 Extra,
249 of 423 General. They exist so a coverage claim can be checked with `grep` instead
of by opening a 203-page PDF, and so the pool is diffable when NCVEC withdraws a
question.

**They are derived data. Do not hand-edit them.** Change the pipeline and rerun:

```bash
./scripts/build_pool_md.sh
```

`scripts/parse_pool.py` does the extraction (and fails loudly on a malformed or
duplicated question); `scripts/emit_md.py` holds the scope and formatting rules.

Three things each file records that the PDF does not make obvious:

- **Which subelements are in scope.** Whole subelements are kept or dropped — nothing
  inside a kept subelement is filtered, because a question missing from the extract is
  a coverage gap we would never notice.
- **Which questions are absent from the export**, with the reason where the HamExam
  change log gives one. Five absences are *unexplained* and flagged as such: `E9E10`,
  `G1C08`, `G1C10`, `G6B09`, `G9C06`. An earlier round of work assumed three of these
  were an extraction fault. They are not — the IDs appear nowhere in the PDF text.
- **Which questions need a figure** (32 of them) and so cannot be answered from the
  markdown at all.

## Cycles

| Pool | Cycle | Valid through |
|---|---|---|
| Element 4 (Extra) | 2024–2028 | 2028-06-30 |
| Element 3 (General) | 2023–2027 | 2027-06-30 |

Both were printed from hamexam.org on 2026-07-28, and the cycle dates come from that
site's pool table, not from the PDFs — the General export in particular carries no
cycle dates internally, which previously led us to doubt them.

Pool wording changes each cycle and NCVEC withdraws questions mid-cycle, so final exam
preparation should still be checked against the official current pool.
